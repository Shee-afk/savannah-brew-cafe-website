SAVANNA BREW CAFE WEBSITE
=========================

Project contents
- index.html: Home page
- about.html: About Us page
- menu.html: Menu and prices
- gallery.html: Gallery page
- contact.html: Contact and reservation form
- css/style.css: Shared external stylesheet
- images/: Local SVG illustration placeholders

How to view
1. Extract the ZIP file.
2. Open index.html in a modern web browser.
3. Use the navigation bar to visit all five pages.

Notes
- The local SVG artwork is placeholder imagery, provided so every image path works
  offline. Replace these SVG files with café photographs if photographs are supplied.
- The reservation form uses a mailto action. It opens the visitor's configured email
  application; a live website would need a server-side form handler to store requests.
- Google Fonts are loaded online with Georgia and Arial fallbacks.
- HTML and CSS should be checked with the W3C Markup Validator and W3C CSS Validator
  before final submission. Local checks were completed: all five pages have the expected HTML structure,   all local links and image paths resolve, the CSS parser reports no syntax errors, and the gallery has   eight figures. The official W3C online validators have not been run.
- Rename the ZIP file using your own name and registration number if required.
